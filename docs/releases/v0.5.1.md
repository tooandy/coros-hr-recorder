# COROS HR Recorder v0.5.1 — 界面、历史记录与深浅色主题

发布日期：2026-11-11。Android `versionCode 12`，`versionName 0.5.1`。

## 本版更新（简体中文）

### 运动操作界面
- 将原来过长的单页拆分为底部 **运动 / 历史记录 / 设置** 三栏；切换页面不停止后台心率采集。
- 运动页突出实时心率及开始、停止并保存操作；停止保存增加二次确认，防止跑步中误触。
- 竖屏和横屏心率图表采用 Android WindowInsets 安全区域，规避状态栏、导航栏和屏幕摄像头挖孔。
- 心率语音提醒从“当前心率150次每分钟”简化为 **“当前心率150”**；英文为 “Current heart rate 150”。试听同步使用短句。

### 历史记录管理
- 每条活动可自行设置 **名称、备注**；原始 CSV/FIT 文件名和记录内容保持不变。
- 按名称、备注、日期、原始文件名搜索；可按年月筛选和分组，按时间正序/倒序或名称排序，只看有备注的活动。
- 大量记录分批加载（每次最多额外展示 60 条）；横屏图表会优先打开历史页选中的旧记录，并显示自定义名称。
- 自定义名称与备注保存在设备上的 App 私有设置中，不会自动写入导出的 FIT/CSV；卸载前应备份重要运动记录和备注。

### 外观与自动化
- 新增 **浅色 / 深色 / 跟随系统** 三种外观模式（默认跟随系统）；运动页、历史、设置、横屏曲线、输入框与系统栏使用相应配色。
- **自动连接上次心率臂带** 和 **连接成功后自动开始记录** 拆为两个独立开关，可分别开启或关闭；手动连接也可以触发自动录制。
- 延续原有设置，切换外观不会停止已经开始的记录。
- 去除旧应用图标中可见的白色外边框，重新生成各 DPI 的桌面与自适应图标。

## 安装包与签名说明（重要）

GitHub Actions 自动产出 **`COROS-HR-v0.5.1-universal-debug.apk`**，这是通用架构的**CI 调试签名测试包**；签名可能不同于此前的 GitHub/本地构建，因此不保证能够覆盖升级。

另提供 **`COROS-HR-v0.5.1-NAS-compatible.apk`**（如在附件中），此包由开发设备使用此前 NAS 测试版相同的本地开发签名生成，供已安装 NAS v0.5.0、rc1–rc4 的设备覆盖升级。它仍是 **开发/测试签名，并非生产发布证书**，不应用于要求严格签名密钥管理的公开正式分发。两个 APK 的程序功能相同、签名不同；**不要来回安装不同签名版本**。各自的 SHA-256 校验值见附件校验文件。

> 通过签名兼容的安装包覆盖安装通常可保留 App 私有记录与设置；卸载 App 可能删除这些数据，请先导出重要 CSV/FIT。该行为也需受手机系统策略约束。

### 已知限制
- Android TTS 需要系统提供对应语言的语音引擎，省电策略可能延迟熄屏时定时语音提醒。
- 暂未实现运动暂停/继续；“停止并保存”会结束当前记录。
- GPS 和步幅指标为手机传感器估算，需结合实际运行环境；不提供医学用途或未经验证的 HRV。
- 本版功能已通过构建与离线回归测试，界面、安全区与手机系统深浅色的最终体验仍以实际设备为准。

## English summary

- Reorganized into **Workout / History / Settings** bottom navigation, with more prominent recording actions and confirmation before stopping; Android safe-area handling for portrait/landscape camera cutouts.
- Session titles, personal notes, full-text search, month filter/grouping, oldest/newest/name sorting, notes-only filter and incremental history rendering. Original data filenames remain unchanged.
- **Light, Dark, and Follow system** appearance options, including the landscape HR comparison chart.
- Independent **auto-connect last sensor** and **auto-start recording after connection** toggles.
- Shorter TTS phrase: “Current heart rate 150” / “当前心率150”; launcher icon without white edge.
- One universal Java-only APK (ARM32/ARM64/x86/x86_64). The CI artifact is debug-signed; the optional NAS-compatible APK uses a different, locally retained debug key. Choose the package that matches your previously installed signing certificate.
