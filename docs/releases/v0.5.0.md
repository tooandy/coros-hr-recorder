# COROS HR Recorder v0.5.0 / 首次公开源码发布

**中文：** v0.5.0 为首个公开源码版本，增加完整的中英文资源、Android 桌面图标、自动连接上次心率臂带、可选 GPS/步数采集与去噪、定时心率语音提醒（含试听），并保留原始 BLE 心率 CSV、Garmin FIT 导出、历史曲线对比和被动 BLE 诊断。此仓库不包含个人轨迹、私有地址、密钥或此前私有仓库的提交历史。

**English:** Initial public-source release. Includes en/zh localization, launcher icon, auto-connect, GPS and step logging with noise filtering, periodic TTS heart-rate reminders and previews, FIT/CSV export, chart comparisons, and passive BLE diagnostics.

## APK / 架构

The single **universal Android APK** supports ARM 32/64-bit and x86 32/64-bit because the application uses no native libraries. Built by GitHub Actions; no per-ABI build is required.

**Signing warning / 签名注意：** The attached APK uses CI's debug signing key for testing. This key can differ between workflow executions and from previous local releases. The APK may not support an in-place upgrade. Uninstalling an earlier build can remove its app-private data; back up your sessions beforehand. This is not a production-signed Play Store release.

## Verification / 验证

Automated Java, FIT, BLE, GPS, reminder and localization tests are configured in Actions. Real-device Chinese TTS output, OEM sleep restrictions, and GPS accuracy are not guaranteed by CI and require device-side testing.

## Privacy / 隐私

No accounts or network upload; exported FIT/GPS files can reveal location. No native HRV estimation is claimed without RR/IBI intervals. COROS is a third-party mark; this project is independent.
